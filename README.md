# Docker-Basics-Assignment

Docker Basics Assignment
1. Dockerize the Services
•	Create Docker containers for the following services:
o	A Web Service (Java Spring Boot). – created customerManagementAPI to create a new customer.
o	A Database Service ( MySQL). – used official mysql image from docker hub
o	A Cache Service ( Redis). – used official redis image from docker hub
•	Write Dockerfiles for each service to build custom Docker images.
2. Configure Service Communication
•	Set up Docker networking to enable communication between the web, database, and cache services.
3. Use Docker Compose
•	Create a Docker Compose file to define and orchestrate the multi-service application. Ensure all services are included and properly configured.
4. Push Docker Images to a Registry
•	Build and push your Docker images to a Docker registry (e.g., Docker Hub). Provide the image links in your documentation.
•	docker pull adityagautam1909/docker-assignment-basic
